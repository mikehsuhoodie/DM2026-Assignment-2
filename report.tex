\section*{5. Enhancing K-means Clustering with Association Rule Mining}
\subsection*{Method Design}
\textbf{ARM-guided feature weighting for K-means}

The idea is to use association rule mining as a feature-importance discovery step before clustering. K-means treats every standardized feature equally, but some mobile specifications are more strongly associated with the price-range structure than others. The improved method therefore:
\begin{enumerate}
    \item Discretizes every feature into categorical items. Numeric features with many unique values are split into low, medium, and high groups using quantiles; binary or small-cardinality features keep their original values.
    \item Adds the class item \texttt{price\_range\_k} to each transaction and mines frequent itemsets/rules.
    \item Keeps association rules whose consequent is a price-range label and whose lift is greater than 1.
    \item Converts the rule strengths into feature weights using $\text{support} \times \text{confidence} \times \text{lift}$.
    \item Runs K-means on standardized features multiplied by the ARM-derived weights.
\end{enumerate}
This is inspired by supervised feature weighting and association-rule-based feature selection: rules with high support, confidence, and lift identify features that are more informative for the target structure, and K-means is then encouraged to cluster along those dimensions.

\begin{enumerate}
    \item Original K-means reaches average Accuracy=0.2962, Precision=0.2959, Recall=0.2962, and F1=0.2941 over the required seeds.
    \item ARM-guided weighted K-means reaches average Accuracy=0.5307, Precision=0.5068, Recall=0.5307, and F1=0.4972.
    \item The F1 improvement is 0.2031, showing that ARM-derived feature weighting makes K-means align better with the price-range labels.
    \item The improvement comes from emphasizing features that appear in high-support, high-confidence, lift-positive rules for the price ranges. This changes the distance geometry used by K-means without changing the clustering algorithm itself.
    \item A limitation is that the ARM weighting step uses label-consequent rules, so this method is best viewed as a semi-supervised enhancement rather than a purely unsupervised clustering method.
\end{enumerate}
